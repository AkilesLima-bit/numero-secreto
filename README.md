<h1>Jogo do número secreto</h1>

<h2>📜 Sobre</h2>
<p>Jogo do Número Secreto é um projeto interativo desenvolvido durante os cursos de Lógica de Programação da Alura. O objetivo é simples: o jogador deve tentar adivinhar qual o número misterioso gerado aleatoriamente pelo sistema. A cada tentativa, o jogo fornece dicas se o número secreto é maior ou menor que o palpite, desafiando o raciocínio lógico até que o usuário acerte. Desenvolvido com HTML, CSS e JavaScript, o projeto demonstra conceitos fundamentais de programação, como manipulação de eventos, geração de números aleatórios e interação com o DOM.

</p>

## 🎯 Funcionalidades

- 🎲 **Geração aleatória** – Número secreto sorteado a cada partida
- ⌨️ **Entrada de palpite** – Sistema valida o número digitado
- 💡 **Dicas dinâmicas** – Informa se o número é maior ⬆️ ou menor ⬇️
- 🔢 **Contador de tentativas** – Mostra quantas tentativas foram feitas
- 🔊 **Feedback visual** – Mensagens claras sobre o resultado
- 🔄 **Reinício rápido** – Botão "Novo jogo" sem recarregar a página
- 🛡️ **Validação de entrada** – Bloqueia números inválidos ou fora do intervalo
- 📱 **Design responsivo** – Funciona em qualquer dispositivo
